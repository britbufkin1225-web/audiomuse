# Affective Psychoacoustics and Temporal DSP Sources

Phase 12E source notes. Each file records one registered source: its citation, its evidence class, what
was actually retrieved, what it is allowed to support in AudioMuse, and what it does not settle.

The retrieval line is the important one. `full text` means the cited work or page was read in full;
`partial text` means the cited portion was read and the whole work was not; `citation only` means the
citation was verified without reading the text. That line is transcribed into `evidence_class` and
`retrieval` in `sources/source-registry.yaml` for any source a claim record cites, following the
Phase 12D contract in `docs/claim-provenance-model.md`.

Phase 12E deliberately registers only sources that were retrieved. Several works that dominate this
literature — Meyer's *Emotion and Meaning in Music*, Huron's *Sweet Anticipation*, Bregman's *Auditory
Scene Analysis*, Zwicker and Fastl's *Psychoacoustics*, Roads' *Microsound*, Blauert's *Spatial
Hearing* — are **not** registered, because AudioMuse has not read them. Where their content matters it
is carried as an attributed statement about what a retrieved source says about them, never as a direct
citation. `docs/affective-mechanism-stack.md` records that boundary as an open research gap.
