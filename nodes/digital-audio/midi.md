# MIDI

MIDI communicates instructions such as note on, note off, velocity, and controller changes. It describes musical events and gestures; it does not store the resulting waveform.

That separation lets one performance control different synthesizers, samplers, and software instruments. MIDI connects pitch and rhythm to sequencing while keeping control data distinct from recorded or synthesized audio.
